# ScriptTemperatura

**Descripcion**

Script creado para simular un sensor de calor y humedad en una planta. devolvera a una api la temperatura en Celsius (C°) y porcentaje de humedad (%)

**Librerias**

numpy: Para manejar de mejor manera la posiblidad de sacar un rango aceptable en la temperatura y humedad
fastapi: Para conectar con la base de datos
